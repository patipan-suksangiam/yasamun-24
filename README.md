- ไฟล์หลัก: `24.html` (เปิดได้โดยตรงในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร)
- อ้างอิงข้อมูล: ประกาศกระทรวงสาธารณสุข เรื่อง ยาสามัญประจำบ้านแผนโบราณ 24 ขนาน
- ภาพสมุนไพร: MedThai.com + Wikipedia (ดึงแบบ dynamic/ลิงก์ตรง)

## ฟีเจอร์
- ทะเบียนตำรับ 24 ขนาน พร้อมสรรพคุณ น้ำกระสายยา ขนาดรับประทาน
- วัตถุส่วนประกอบพร้อมสัดส่วน (X ส่วน) ตามตำรับทางการ
