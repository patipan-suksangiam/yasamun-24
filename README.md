# ตำรับยาสามัญประจำบ้านแผนโบราณ 24 ขนาน — คู่มือการเรียนรู้

ระบบสืบค้นโครงสร้างเภสัชกรรมไทย: ตัวยาตรง, ช่วย, ประกอบ, ชูกลิ่นชูรส พร้อมคลังภาพสมุนไพร

**ลิงก์ใช้งานสาธารณะ (ไม่ต้องติดตั้งอะไร):** https://patipan-suksangiam.github.io/yasamun-24/

- **ฉบับหลายหน้า (ปัจจุบัน)** — `index.html` = หน้าหลักแยกตามกลุ่มอาการ → 24 หน้าตำรับ (`ตำรับ-01…24`) · `สมุนไพร.html` = ทะเบียนสมุนไพร · `สมุนไพร/*.html` ≈ 199 หน้า
- **ฉบับไฟล์เดียว (เดิม)** — `v1.html` เปิดไฟล์เดียวจบ (ใช้รูปจาก `img24/`) ยังใช้งานได้เหมือนเดิม
- **รูปสมุนไพร** — `images/` (ย่อ ~4 MB ใช้แสดงผล) + `images_hi/` (เต็ม ~35 MB ใช้ตอนซูม) ชื่อไฟล์อ้างตรงกับชื่อสมุนไพร
- อ้างอิงข้อมูล: ประกาศกระทรวงสาธารณสุข เรื่อง ยาสามัญประจำบ้านแผนโบราณ 24 ขนาน

## ฟีเจอร์
- ทะเบียนตำรับ 24 ขนาน พร้อมสรรพคุณ น้ำกระสายยา ขนาดรับประทาน
- วัตถุส่วนประกอบพร้อมสัดส่วน (X ส่วน) ตามตำรับทางการ
- โหมดบัตรคำท่องจำ (Flashcard)
- คลังภาพสมุนไพรเดี่ยว คลิกที่ชื่อสมุนไพรในตำรับเพื่อดูรูปและสรรพคุณ

> ใช้เพื่อการศึกษาเท่านั้น — ไม่ใช่คำแนะนำทางการแพทย์

## การตรวจสอบความถูกต้อง (ล่าสุด)

ตรวจเทียบกับ **ประกาศกระทรวงสาธารณสุข เรื่อง ยาสามัญประจำบ้านแผนโบราณ พ.ศ. 2556**
(ราชกิจจานุเบกษา เล่ม 130 ตอนพิเศษ 21 ง วันที่ 14 กุมภาพันธ์ 2556 หน้า 30–49)

- วัตถุส่วนประกอบ + สัดส่วน ของทั้ง 24 ตำรับ ตรงตามประกาศ
- แก้ไข **ยาประสะกานพลู** ให้เป็นสูตรตามประกาศ 2556 (เพิ่ม ไพล เจตมูลเพลิงแดง สะค้าน ช้าพลู สิ่งละ 2 ส่วน, พริกไทย 1 ส่วน / ตัด เกลือสินเธาว์ และ กระเทียม ออก ซึ่งไม่ปรากฏในประกาศ)
- เติม **พิมเสน** ในตำรับยาหอมเทพจิตร (ประกาศระบุ 4 ส่วน)
- ตัวยาตรง/ช่วย/ประกอบ/ชูกลิ่นชูรส จัดใหม่ให้ **มีแต่ตัวยาที่ปรากฏในประกาศของตำรับนั้น** และตัวยาตรงคือตัวยาหลัก (สัดส่วนมากสุด/ตามชื่อตำรับ)
